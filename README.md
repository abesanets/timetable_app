# Расписание МГКЦТ - Android приложение

Android-клиент для просмотра расписания МГКЦТ: расписания групп и преподавателей, звонки для корпусов, справочник сотрудников, офлайн-кэш, автообновления и виджет рабочего стола.

## Основные возможности

- **Расписание групп**: загрузка актуального недельного расписания с сайта колледжа по номеру группы с подсказками по специальностям.
- **Расписание преподавателей**: поиск преподавателя по фамилии и поддержка многонедельных расписаний.
- **Динамический статус дня**: отображение времени до начала пары, перерыва, звонка или окончания пары в реальном времени.
- **Умная навигация**: автоматическое центрирование текущего или следующего учебного дня при открытии приложения.
- **Детали занятий**: просмотр точного времени пары, аудитории, преподавателя и данных по подгруппам в нижней панели.
- **Настройки подгруппы**: фильтрация расписания по подгруппам (все, 1-я или 2-я) с сохранением выбора.
- **Офлайн-доступ**: кэширование последней группы и расписания через DataStore Preferences.
- **Встроенные обновления**: проверка новых версий через GitHub Releases API и установка APK прямо из приложения.
- **Расписание звонков**: поддержка звонков корпусов Казинца, 91 (1 и 2 смены, монолитные пары) и Кнорина, 14.
- **Справочник персонала**: контакты администрации и преподавателей с быстрым переходом к их расписанию.
- **Виджет рабочего стола**: компактный Jetpack Glance виджет с поддержкой ручного и фонового обновления через WorkManager.
- **Интерфейс**: Jetpack Compose, Material 3, dynamic colors (Material You), edge-to-edge, поддержка тёмной темы.

## Архитектура и технологии

- **Язык**: Kotlin 2.2.10 (Java 1.8 compatibility)
- **UI**: Jetpack Compose, Material 3, Navigation Compose
- **Сеть и парсинг**: OkHttp 4, Jsoup
- **Хранение данных**: DataStore Preferences, Gson
- **Фоновые задачи**: WorkManager, Coroutines
- **Виджеты**: Jetpack Glance (Glance Material 3)
- **Архитектура**: Feature-based модульная структура

## Структура проекта

```text
app/src/main/java/com/example/schedule/
├── core/        # Общие утилиты, маппинг корпусов и расписание звонков
├── data/        # Модели данных, сетевой загрузчик, HTML-парсер, хранилище Preferences
├── features/
│   ├── alarms/   # Сетки звонков корпусов
│   ├── schedule/ # Экраны расписания, карточки дней, фильтрация подгрупп
│   ├── settings/ # Настройки подгрупп и интервалов обновления виджета
│   ├── staff/    # Справочник персонала и преподавателей
│   ├── update/   # Менеджер проверки и установки обновлений с GitHub
│   └── widget/   # Jetpack Glance виджет и фоновый воркер
└── ui/          # MainActivity, навигация и тема Material You
```

## Требования

- **Android**: API 24+ (Android 7.0+)
- **Target SDK**: API 34
- **Compile SDK**: API 34
- **JDK**: Java 17 / 21

## Сборка и тестирование

Сборка Release APK:
```bash
./gradlew assembleRelease
```

Сборка Debug APK:
```bash
./gradlew assembleDebug
```

Запуск юнит-тестов:
```bash
./gradlew testDebugUnitTest
```
